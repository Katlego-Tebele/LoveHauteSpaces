## 🐛 Common Issues & Fixes

**Issue: Images not showing**
- ✅ Check filenames match exactly (case-sensitive)
- ✅ Ensure images are in correct folder
- ✅ Check file extensions (.jpg, .png)

**Issue: WhatsApp links not working locally**
- ✅ This is normal! They work once deployed online
- ✅ Test after deployment

**Issue: Menu doesn't scroll smoothly**
- ✅ Try different browser
- ✅ Check if JavaScript is enabled

**Issue: Lightbox doesn't open**
- ✅ Ensure JavaScript is enabled
- ✅ Check browser console for errors (F12)

**Issue: Mobile menu doesn't open**
- ✅ Try different browser
- ✅ Check if JavaScript is enabled

**Issue: Form doesn't submit**
- ✅ Fill in all required fields
- ✅ Check if JavaScript is enabled
